# Landing Page — Portaria

Projeto de landing page implementado em HTML, CSS e JavaScript puro, seguindo o styleguide fornecido.

Como publicar no GitHub Pages:

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta (`index.html`, `styles.css`, `script.js` e assets) para a branch `main` (ou `gh-pages`).
3. No repositório GitHub: Settings → Pages → Branch: `main` (root) → Save.
4. Aguarde alguns minutos; a página estará disponível em `https://<seu-usuario>.github.io/<seu-repo>/`.

Observações:
- O design segue o modo escuro com destaque em verde conforme o styleguide.
- Para integração real de formulários/submissões, conecte `script.js` a uma API backend.
